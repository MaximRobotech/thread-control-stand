THREADCONTROL — локальная демонстрация

Как открыть сайт:

1. Сначала полностью распакуйте архив в отдельную папку.
2. Откройте файл index.html двойным щелчком.
3. Рекомендуемые браузеры: Google Chrome или Microsoft Edge.

Интернет, сервер и установка программ не требуются. Все стили, скрипты и
изображения уже встроены в HTML-файл.

Если браузер показывает пустую страницу:

- не открывайте HTML прямо внутри ZIP-архива;
- выберите «Открыть с помощью» → Chrome или Edge;
- при необходимости скопируйте распакованную папку на локальный диск и
  откройте файл повторно.

В состав версии входит отдельный продукт UMC—01: автономный универсальный
модуль контроля резьбы для установки на промышленного робота или подвесной
механизм, с техническим зрением, датчиками, экраном, встроенным ПО и
автоматической сменой проходного/непроходного калибров.
